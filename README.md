# 🚗 Car Roulette

## 📖 About
Car Roulette is a web-based companion game for Forza Horizon, designed for 3 or more players. The goal is to compete against others, randomize your vehicle, and claim first place!

This is a completely revamped version of the original project. While the core gameplay remains the same, it now features a **modernized architecture** and a **significantly improved UI/UX design**, built from the ground up with Vue 3 and TypeScript.

## 🛠 Tech Stack
- **Framework:** Vue 3 (Composition API, `<script setup>`)
- **Language:** TypeScript
- **Build Tool:** Vite
- **State Management:** Pinia
- **Routing:** Vue Router
- **Styling:** Modern CSS (CSS Variables, Global Styles)

## 🚀 Installation & Running

To run the project locally, follow these steps:

1. Clone the repository:
   ```bash
   git clone https://github.com/DuneFyq/Car-Roulette
   cd Car-Roulette
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Build the project for production:
   ```bash
   npm run build
   ```

5. Preview the production build locally:
   ```bash
   npm run preview
   ```
